LQConditionEditorTests contains the tests for LQConditionEditor in Liquid-UI.

It drives the UIManager dialogs via ProvideAnswerNotification (see LQTestCase>>run:answering:).

Instance Variables
	editor:		<LQConditionEditor>
	pollDraft:	<LQPollDraft>

editor
	- the editor under test

pollDraft
