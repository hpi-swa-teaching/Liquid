A LQConditionEditor runs the interactive workflow for adding or removing a question condition on a poll-draft. It pops the modal pickers (trigger question, trigger choice) and writes the resulting LQQuestionCondition to the given poll-draft. It is stateless: the poll-draft and the target question index are passed in per call, so it always operates on the caller's current selection. The add/remove methods answer a Boolean indicating whether the draft was changed, so the caller can refresh accordingly.
