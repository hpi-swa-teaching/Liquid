A LQDeadlineMenu is UI dialog for picking the deadline of a poll draft. Lets the host select day, month, year, hour and minute from lists and writes the resulting deadline back to the poll draft. Extracted from LQPollDraftBuilder.

Instance Variables
	day:		<Integer> selected day of month
	month:		<Integer> selected month
	year:		<Integer> selected year
	hour:		<Integer> selected hour
	minute:		<Integer> selected minute
	pollDraft:		<LQPollDraft> the draft whose deadline is being edited
